5. INTERPRETATION

The endpoint annual rasters, endpoint-change rasters, and reconstructed
hotspot-persistence rasters cover the same 528 AOI grid cells when reduced with
the declared CRS and scale. The endpoint annual assets are strictly complete
(12/12 months) and publication-eligible for NO2 and CO.

The audit supports using 528 as the unweighted valid-cell count for these
products. It does not support interpreting 698, or any fractional weighted
sum, as a raster-cell count.

6. PROJECTION NOTE

The stored annual and absolute-change rasters report the declared EPSG:4326
grid. The reconstructed in-memory persistence images report Earth Engine's
default projection [1, 0, 0, 0, 1, 0]. This is a metadata/projection-state
difference, not a detected support difference: all audit reductions explicitly
set EPSG:4326 and 1113.2 m and return 528 cells.

For any future persistence export, the export call must explicitly specify the
publication CRS and scale (or an exact crsTransform) so that the stored raster
grid is deterministic. This audit alone does not prove that an independently
exported persistence GeoTIFF inherited the annual raster transform.

7. SCOPE LIMITS

This audit validates spatial support, completeness properties, sign counts,
and selected hotspot-occurrence counts. It does not independently validate the
scientific interpretation of causality, surface concentrations, emissions, or
regulatory compliance. The complete NO2 occurrence histogram was not expanded
in the supplied Console record; therefore no additional NO2 class counts are
asserted here.
