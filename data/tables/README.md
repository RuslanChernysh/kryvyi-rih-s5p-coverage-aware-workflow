# Publication data tables

This directory contains the tabular data products used to support the analyses, quality-control assessment, figures, and reported results of the Kryvyi Rih Sentinel-5P study for 2019–2024.

The files are direct publication-run outputs or derived reporting tables associated with the archived scientific workflow.

## Files

### `ARTICLE4_FINAL_TABLE2_MONTHLY_AOI_STATISTICS_2019_2024_R01.csv`

Monthly AOI-level statistics for the study period.

This table contains the monthly atmospheric-pollutant statistics used for the temporal analysis and reporting of the Sentinel-5P results over the Kryvyi Rih area of interest.

---

### `ARTICLE4_FINAL_TABLE3_MONTHLY_QC_2019_2024_R01.csv`

Monthly quality-control and data-completeness table.

It records the temporal support and QC information used to evaluate the reliability and availability of the monthly Sentinel-5P products before their use in subsequent analyses.

---

### `ARTICLE4_FINAL_TABLE4_SEASONAL_ANNUAL_SUMMARY_2019_2024_R01.csv`

Seasonal and annual summary table for 2019–2024.

This file contains aggregated statistics used for the seasonal and interannual interpretation of the study results.

---

### `ARTICLE4_FINAL_ACCEPTANCE_MANIFEST_2019_2024_R01.csv`

Final acceptance manifest for the publication run.

The manifest records the acceptance status of the principal outputs and provides a compact provenance record for the final scientific data products used in the study.

---

### `ARTICLE4_FIG3_TIME_SERIES_DATA_2019_2024_R01.csv`

Source data for the time-series figure.

This table contains the numerical values underlying the temporal visualization used in the publication and allows the corresponding figure to be independently inspected or reproduced.

---

### `ARTICLE4_FIG7_AVAILABILITY_DATA_2019_2024_R01.csv`

Source data for the data-availability/completeness figure.

This table contains the numerical values used to visualize temporal data availability and observational support in the publication.

## Scope

Study area: Kryvyi Rih, Ukraine  
Study period: 2019–2024  
Satellite data source: Sentinel-5P/TROPOMI OFFL products  
Processing environment: Google Earth Engine

The exact AOI provenance and reconstruction information are documented in:

`../README_AOI.md`

`../../code/`

Independent validation and audit records are available in:

`../../validation/`

## Reproducibility note

These tables are preserved as machine-readable publication data so that the numerical basis of the reported results, quality-control decisions, and selected figures can be independently inspected without relying only on the manuscript or graphical representations.

The tables should be interpreted together with the documented processing workflow, QC rules, AOI definition, and validation records contained in this repository.
