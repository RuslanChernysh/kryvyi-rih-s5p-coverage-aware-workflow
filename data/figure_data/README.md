# Figure-supporting data

This directory contains the machine-readable tabular data used to support selected figures in the Kryvyi Rih Sentinel-5P study for 2019–2024.

These files preserve the numerical data underlying the corresponding publication visualizations and provide a direct link between the archived scientific workflow, reported results, and figure construction.

## Files

### `ARTICLE4_FIG3_TIME_SERIES_DATA_2019_2024_R01.csv`

Source data for Figure 3.

This file contains the time-series values used to represent the temporal evolution of the analysed Sentinel-5P atmospheric-pollutant products over the Kryvyi Rih area of interest during the 2019–2024 study period.

It provides the machine-readable numerical basis for the corresponding time-series visualization.

---

### `ARTICLE4_FIG6_SO2_SELECTED_SEASONS_MAM_JJA_2024_R01.csv`

Source data supporting Figure 6.

This file contains the selected SO2 seasonal data for March–April–May (MAM) and June–July–August (JJA) 2024 used in the corresponding publication analysis and visualization.

The selection reflects the temporal-support and quality-control logic applied by the scientific workflow.

---

### `ARTICLE4_FIG7_AVAILABILITY_DATA_2019_2024_R01.csv`

Source data for Figure 7.

This file contains the data-availability and temporal-support information used to construct the corresponding publication visualization.

It documents differences in observational support across the analysed Sentinel-5P products and provides the machine-readable basis for the availability assessment shown in the figure.

## Scope

The files in this directory are figure-supporting tabular products rather than independent raw satellite datasets.

They should be interpreted together with the methodological documentation, quality-control tables, scientific raster products, and other provenance information provided in this repository.

Missing or unavailable observations are preserved according to the workflow logic and should not be interpreted as zero pollutant values.

## Reproducibility

Providing the numerical source data separately from the rendered publication figures improves traceability and allows the reported visualizations to be independently inspected or reconstructed from the archived results.

The figure-supporting data originate from, or are derived from, the same publication-run workflow documented in this repository.
