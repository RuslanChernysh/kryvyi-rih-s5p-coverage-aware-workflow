# Publication data tables

This directory contains the principal tabular data products generated by the final publication workflow for the Kryvyi Rih Sentinel-5P study for 2019–2024.

The files are corrective-release `R02` outputs generated for software release `v1.1.1`. They supersede the corresponding `R01` publication tables previously included in the repository.

The `R02` tables preserve the verified scientific processing logic while correcting and clarifying the provenance of AOI raster-cell counts, publication-output naming, and associated metadata.

## Files

### `ARTICLE4_FINAL_TABLE1_METHOD_METADATA_2019_2024_R02.csv`

Methodological metadata for the final publication workflow.

This table records the principal processing configuration required to interpret the Sentinel-5P products, including:

- study period and AOI identifier;
- pollutant-specific processing branches;
- source collections and analysed bands;
- aggregation methods;
- quality-control and temporal-support rules;
- AOI reduction CRS and scales;
- units of the reported satellite column quantities;
- workflow and output version identifiers.

The SO2 AOI reduction scale of 7000 m is a predefined analysis scale evaluated through a separate scale-sensitivity audit. It must not be interpreted as an empirically optimized spatial scale or as the native spatial resolution of Sentinel-5P/TROPOMI.

---

### `ARTICLE4_FINAL_TABLE2_MONTHLY_AOI_STATISTICS_2019_2024_R02.csv`

Monthly AOI-level Sentinel-5P statistics for the complete 2019–2024 study period.

The table contains one record for each pollutant–month combination and provides the monthly values used for temporal analysis and reporting over the Kryvyi Rih area of interest.

The complete table contains:

- 72 calendar months;
- three pollutant branches: NO2, CO, and SO2;
- 216 pollutant–month records in total.

Unavailable SO2 monthly results are retained as missing values according to the workflow logic and are not replaced with zero.

The `R02` version uses the verified AOI raster support convention. Where an unweighted raster-cell count is reported for the approximately 0.01-degree analysis grid, the verified count is **528 cells**. The historical value of 698 obtained from a combined mean-and-count reduction must not be interpreted as a standalone count of valid raster cells.

---

### `ARTICLE4_FINAL_TABLE3_MONTHLY_QC_2019_2024_R02.csv`

Monthly quality-control, coverage, and temporal-support table for 2019–2024.

This table documents the evidence used to determine whether individual monthly pollutant products satisfy the applicable pollutant-specific processing and acceptance rules.

It includes information concerning:

- source-image availability;
- temporal support;
- spatial coverage;
- valid or accepted month status;
- missing-data status;
- pollutant-specific quality-control outcomes;
- provenance of the monthly publication products.

The complete table contains 216 pollutant–month records.

Missing or unavailable values are preserved as missing data and must not be interpreted as zero atmospheric-pollutant values.

Where raster-cell support is reported, the verified standalone unweighted AOI raster-cell count is **528** for the applicable approximately 0.01-degree grid and reduction configuration.

---

### `ARTICLE4_FINAL_TABLE4_SEASONAL_ANNUAL_SUMMARY_2019_2024_R02.csv`

Seasonal and annual summary of the accepted publication-run results for 2019–2024.

The table contains pollutant-specific seasonal and annual aggregates derived only where the required temporal-support and completeness conditions are satisfied.

The summary preserves the distinction between:

- complete and incomplete calendar periods;
- accepted and unavailable results;
- pollutant-specific aggregation branches;
- seasonal, annual, and endpoint reporting products.

SO2 seasonal and annual results are reported only when the applicable orbital-monthly availability and completeness requirements are met. Missing periods are not silently interpolated and are not converted to zero.

---

### `ARTICLE4_FINAL_LONG_TERM_SUMMARY_2019_2024_R02.csv`

Long-term summary of the final Sentinel-5P publication products for the complete 2019–2024 study period.

This table consolidates the pollutant-specific long-term results used for endpoint comparison, spatial-change assessment, and interpretation of the accepted publication products.

The values should be interpreted together with:

- the corresponding annual scientific rasters;
- endpoint-change products;
- hotspot-persistence products;
- publication-selection manifests;
- validation and provenance records.

The long-term comparison does not convert Sentinel-5P satellite vertical-column quantities into regulatory near-surface concentrations and does not constitute source-emission inversion.

---

### `ARTICLE4_FINAL_ACCEPTANCE_MANIFEST_2019_2024_R02.csv`

Final acceptance record for the `v1.1.1` corrective publication package.

This manifest documents the acceptance status of the evaluated pollutant-specific products and provides a provenance link between:

- workflow processing branches;
- temporal-support and completeness rules;
- generated publication tables;
- scientific raster products;
- figure-supporting data;
- outputs selected for reporting.

The manifest records publication eligibility and selection decisions. It does not modify the scientific results.

## Corrective-release provenance

The `R02` designation identifies refreshed publication-supporting outputs generated for software release `v1.1.1`.

The corrective release retains the verified scientific processing architecture and incorporates the following provenance clarifications:

- Stage-2A monthly AOI materializations use corrective version `R03`;
- Stage-2B publication tables use corrective version `R03`;
- verified Stage-2C scientific annual assets remain version `R01`;
- final Stage-2D publication exports use corrective version `R02`;
- the standalone unweighted AOI raster-cell count is 528 for the applicable approximately 0.01-degree grid;
- the historical value 698 originates from a combined mean-and-count reduction and is not a valid standalone raster-cell count;
- SO2 missing months remain missing and are not silently interpolated;
- the predefined 7000 m SO2 AOI reduction scale was evaluated through sensitivity analysis and was not selected as an optimal scale.

Detailed evidence supporting these conclusions is provided in the repository `validation/` directory.

## Interpretation

The tables must be interpreted together with the methodological metadata, scientific raster products, figure-supporting data, manifests, source code, and validation records included in the repository.

Sentinel-5P/TROPOMI vertical-column quantities must not be interpreted as directly equivalent to regulatory ground-level pollutant concentrations.

Missing, unavailable, or ineligible observations are preserved according to the workflow logic and must not be treated as zero values.

Pollutant-specific differences in preprocessing, aggregation, quality control, spatial support, and temporal completeness must be considered when comparing NO2, CO, and SO2 results.
